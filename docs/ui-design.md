# IQ 配置页设计系统

## 使用场景与边界

页面位于 Sub2API 插件管理的受限 iframe 中，面向配置评测接口与账号策略的管理员。
信息顺序为「运行概览 → 评测范围 → 评分接口 → 高级设置 → 保存反馈」。
运行概览仅展示 `plugin.status` 返回的计数，不推导评分趋势、成功率或账号目录。
指标是当前插件进程的累计值，不表示某个时间窗口。

页面使用原生 HTML、CSS、JavaScript、系统字体和官方 Bridge，不依赖远程字体、CDN、
运行时包、Cookie 或本地存储。草稿仅保存在页面内存中。

## 视觉令牌

令牌的唯一实现位于 `plugin/ui/assets/app.css`，明暗模式跟随系统偏好。

| 语义 | CSS 变量 | 浅色 | 深色 |
| --- | --- | --- | --- |
| 页面背景 | `--bg` | `#f4f6f9` | `#0f1724` |
| 卡片与输入底色 | `--surface` | `#ffffff` | `#182234` |
| 次级区域 | `--surface-muted` | `#eef2f7` | `#202d42` |
| 正文 | `--text` | `#17243a` | `#edf2fa` |
| 次级文字 | `--muted` | `#526179` | `#aab8cc` |
| 主操作 | `--accent` | `#2455cf` | `#a9c5ff` |
| 主操作文字 | `--on-accent` | `#ffffff` | `#102347` |
| 输入边界 | `--control-border` | `#7c8ba2` | `#71839d` |
| 成功 | `--success` | `#176344` | `#89ddbc` |
| 警告 | `--warning` | `#85500a` | `#f4cd7e` |
| 错误 | `--error` | `#b42332` | `#ffacb2` |

- 字体：系统无衬线用于中文界面，系统等宽字体用于规则输入与代码；数字采用等宽数字。
- 间距：4、8、12、16、24、32px；卡片 24px 内边距，手机 18px。
- 圆角：卡片 14px，输入与按钮 8px；正文不使用装饰渐变。
- 控件：输入框、按钮、开关交互区最小高度 44px；键盘焦点使用 3px 轮廓。
- 动效：只用于颜色与开关位移，160ms；遵循 `prefers-reduced-motion`。
- 布局：内容最大宽度 1040px；700px 以下指标变两列；480px 以下表单单列，保存区回归正常文档流。
- 状态必须同时提供文字说明；颜色只作辅助。深色主按钮采用深色文字保证可读性。

UI UX Pro Max 的检索支持简洁后台界面、可见焦点、错误摘要及字段错误关联。
检索返回的营销落地页结构不适用于本插件；信息架构按上述真实配置流程确定。

## 交互状态

| 状态 | 页面行为 |
| --- | --- |
| 未连接宿主 | 显示入口说明，禁止读取和保存配置 |
| 配置加载失败 | 禁用编辑，提供重试 |
| 已载入且未修改 | 保存按钮禁用，允许保存并测试 |
| 存在修改 | 显示未保存标记与草稿范围；恢复原值后自动清除标记 |
| 校验失败 | 聚焦错误摘要，提供字段链接及 `aria-describedby`；高级字段有错时展开高级设置 |
| 保存 / 测试进行中 | 锁定编辑和重复提交；保存成功后才测试已保存配置 |
| 保存失败 | 保留草稿，不执行测试 |
| 保存响应超时 | 重新读取宿主结果并保留草稿；核对失败时阻止保存和测试，提供再次核对入口 |
| 放弃修改 | 页内确认，不依赖 sandbox 不支持的模态弹窗 |
| 状态刷新失败 | 保留上次数据并标记过期；并发刷新去重 |

账号规则支持整行或行内 `#` 注释；重复账号、额外逗号、非数字 ID、非法状态与越界采样率
均显示行号错误。所有数字字段要求整数并与后端范围一致；采集上限以字节计，支持范围内任意整数。

诊断提示不回显原始接口错误、接口地址或密钥，不向宿主发送包含配置值的通知。
保存和测试可能要求宿主二次验证；测试会调用一次最小评分请求，页面在按钮下明确说明。

## 本地验收

Go 门禁沿用仓库流程：

```bash
cd plugin
make test
```

UI 测试工具仅用于开发，不打入插件包：

```bash
npm ci
npx playwright install chromium
npm run test:ui
```

`tests/ui.test.cjs` 启动本地模拟宿主，通过真实 `bridge-v1.js`、
`sandbox="allow-scripts"` iframe 和受限 CSP 验证消息流程。测试不调用真实评分接口。
覆盖两个保存入口的校验、规则解析、保存与测试顺序、失败/超时恢复、放弃确认、
状态过期、宿主缺失、明暗主题与 320–1440px 布局。

可通过 `UI_SCREENSHOT_DIR` 环境变量指定临时截图输出目录。
真实 Sub2API 的安装、二次验证弹窗、主题嵌入及真实评分接口仍需宿主端验收。
